# Unreal Engine learning library

Start with one short lesson and verify its visible result in a separate practice project.

| Guide | Use it for |
|---|---|
| [Unreal Engine & Blueprint Bible](Unreal_Engine_Blueprint_Bible.md) | Detailed reference: 28 chapters, step-by-step labs, Blueprint fundamentals, troubleshooting, and C++/Blueprint decisions |
| [UE5 beginner’s hands-on guide](UE5_Beginners_Hands_On_Guide.md) | The original shorter introduction to the Colosseum project |

## Choose a first session

- **New to Unreal:** Bible chapters 1–4; finish with one cube printing a message.
- **Learning Blueprint logic:** Chapters 5–9; inspect variables, execution flow, functions, arrays, spawning, and timers.
- **Building interactions:** Chapters 10–13; complete a hinged trapdoor, interaction trace, and player input.
- **Choosing C++ or Blueprint:** Chapter 19, then the complete hybrid health lab in chapter 20.
- **Troubleshooting:** Chapters 22 and 26.
- **Working with teammates:** Chapters 23–24.

The Bible's examples are learning material, not installed game features. Its C++ example has not been compiled in this workspace; run its acceptance checks in the practice project before adapting it to production.
