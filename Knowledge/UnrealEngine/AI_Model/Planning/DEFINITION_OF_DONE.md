# Definition of Done

- [ ] Scope and acceptance criteria approved.
- [ ] RED/GREEN/REFACTOR evidence where applicable; actual regression results.
- [ ] Python/Unreal tests relevant to change pass; otherwise document blocker.
- [ ] ML schema, seeds, grouped splits, leakage, overfitting and evaluation checked where relevant; final holdout untouched during tuning.
- [ ] ONNX parity and runtime compatibility verified when applicable.
- [ ] Python PEP 257/Google docstrings and C++ ownership/lifecycle documentation; actual patterns and rationale.
- [ ] No secrets or unrelated Unreal assets; LFS coordination if necessary.
- [ ] AI-use log updated and explicit owner reading/acceptance recorded.
- [ ] Issue references and commit/PR verified; demo and progress evidence recorded.

One accepted story does not close a grouped issue. All group criteria must pass before Closes #N is permitted. Do not merge main without authorization. Sunday rest and holiday pause.
